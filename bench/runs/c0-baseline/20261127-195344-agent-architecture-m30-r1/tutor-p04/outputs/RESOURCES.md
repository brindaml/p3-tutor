# Agent architecture Resources

## Knowledge

- [Building multi-agent systems: when and how to use them (Anthropic, 2026)](https://claude.com/blog/building-multi-agent-systems-when-and-how-to-use-them)
  Vendor engineering guidance; token figures come from its own testing. Use for: when to split, where to draw boundaries, cost.
- [Towards a science of scaling agent systems (Google Research, 2026)](https://research.google/blog/towards-a-science-of-scaling-agent-systems-when-and-why-agent-systems-work/)
  Summary of a controlled study of 180 configurations ([paper](https://arxiv.org/abs/2512.08296)). Use for: parallel versus sequential tasks.
