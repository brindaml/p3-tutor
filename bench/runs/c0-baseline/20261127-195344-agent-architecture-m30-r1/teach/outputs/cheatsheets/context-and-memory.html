Context and memory

Rule: besides its training, a model has only what is supplied as context.

InformationWhere it livesHow it reaches the model
Instructions, tool definitionsYour programSent with each call
This session's stepsHistory held by program or serviceSupplied again, possibly trimmed
Preferences, job notesPer-student storeLoaded or fetched
ManualsDocuments and search indexRelevant chunks retrieved
Bookings, training statusOfficial recordsLooked up when needed

Memory design

Write, store, read, update. Program code controls whose data can be loaded.

Size and cost

Does it fit? Check one call's input plus output. What is billed? Under per-token pricing, add input over all calls and add output separately. Check caching and pricing rules.

When it goes wrong

  • Print the actual input and the retrieved chunks.
  • Label chunks with machine, manual, section and page.
  • In summaries, keep the goal, things tried, results, open problem and next step.
