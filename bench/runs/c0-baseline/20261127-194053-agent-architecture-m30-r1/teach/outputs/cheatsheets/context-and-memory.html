TermMeaning

Keyword searchMatches words and exact strings, such as codes

Design questions for each piece of information

  1. Does this call need it in context?
  2. Can it change? If so, read the official source fresh.
  3. Needed next session? Then plan how to save, fetch and load it.
  4. Who may read or write it, when does it expire, and how is it corrected?

Token count for a loop

Each call's input = the previous call's input + what was added since (if nothing is removed). Total input = the sum over all calls. The window limit applies to one call, including its output.
