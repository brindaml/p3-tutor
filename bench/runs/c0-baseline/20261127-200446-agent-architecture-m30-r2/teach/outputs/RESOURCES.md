# Agent Architecture Resources

## Knowledge

- [Effective context engineering for AI agents (Anthropic)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context rot, compaction, note-taking, just-in-time retrieval. Primary source for O3.
- [Context windows (Claude docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, overflow, accumulation. Vendor- and model-specific; recheck figures.
- [Working with messages (Claude docs)](https://platform.claude.com/docs/en/build-with-claude/working-with-messages)
  Stateless API and resending history. Checked through search results only; page not fetched.
- [Glossary (Claude docs)](https://platform.claude.com/docs/en/about-claude/glossary)
  Definition of a token.
- [Introducing contextual retrieval (Anthropic)](https://www.anthropic.com/engineering/contextual-retrieval)
  RAG, chunks, BM25 and embeddings, lost chunk context.
- [Memory overview (LangChain docs)](https://docs.langchain.com/oss/python/concepts/memory)
  Short-term (thread) and long-term memory, in one framework's terms.
- [RAG: generate embeddings (Microsoft Learn)](https://learn.microsoft.com/en-us/azure/architecture/ai-ml/guide/rag/rag-generate-embeddings)
  Embedding chunks and queries with the same model.
