Context and memory

Back to the lesson

Context window: limited room, in tokens, shared by system prompt, tool definitions, history, tool results and new output (source).

Token arithmetic (no caching, nothing removed)

  • Next call's input = last call's input + its output + whatever is newly added.
  • Fit: check each call's input plus room for output.
  • Input cost: add the inputs of all calls. Output is priced too.

Crowded context

  • Trim: drop old messages.
  • Clear: replace old bulky tool results with a marker.
  • Compact: summarize older history. Check that key facts survive.

Search

  • Keyword: same words; good for exact codes.
  • Semantic: similar meaning; good for different wording.
  • Hybrid: both. Test with questions whose correct page you know (source).
