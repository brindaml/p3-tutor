# Agent architecture Resources

## Knowledge

- [Anthropic: Effective context engineering for AI agents (2025)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source for lesson 0001. Use for: context as a limited resource, compaction, notes, just-in-time retrieval.
- [Claude docs: Context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Use for: what counts toward a window, limit errors, context rot. Specific to one provider.
- [Claude docs: Using the Messages API](https://platform.claude.com/docs/en/build-with-claude/working-with-messages)
  Use for: statelessness and resending history.
- [Claude docs: Glossary](https://platform.claude.com/docs/en/about-claude/glossary)
  Use for: token and RAG definitions.
- [Claude docs: Pricing](https://platform.claude.com/docs/en/about-claude/pricing)
  Use for: per-token billing and caching. Prices change; re-check.
- [LangChain: Memory overview](https://docs.langchain.com/oss/python/concepts/memory)
  Use for: short-term and long-term memory, when to write memories.
- [Anthropic: Contextual Retrieval (2024)](https://www.anthropic.com/engineering/contextual-retrieval)
  Use for: chunking, BM25, embeddings, lost chunk context. Results are the authors' own tests.
