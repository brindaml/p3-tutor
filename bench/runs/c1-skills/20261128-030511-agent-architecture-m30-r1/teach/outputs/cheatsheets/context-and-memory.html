Context and memory

From lesson 1.

In the window

System prompt + tool descriptions + messages + tool results + the reply. All share one token limit.

Where does each thing go?

InformationRoute into context
Rules, tool descriptionsSent on every call
This session's stepsHistory carried forward (usually your program resends it)
Preferences, project notesSaved outside, dated, loaded later
Training status, calendarOfficial record, checked by tool when needed
Manual contentRetrieved chunks, labelled with manual and page

Crowded window

Clear used tool results (keep the source) → compact (summaries can lose detail) → trim with care. Protect the goal, key constraints and actions already taken.

Search

Keyword: exact codes and words. Embedding: similar meaning. Hybrid: both. Test whether the right page is returned.

Cost

Total input = the sum of what each call is sent, not just the size of the last one.

Memory safety

Separate each student's memory (my recommendation). Validate file paths, filter sensitive data, cap size, expire old files (memory tool docs).
